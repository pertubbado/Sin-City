# C7.9 — Sin City Studio (versão de avaliação)

Esta branch apresenta uma reformulação visual do Editor Visual em três áreas:
- Navegação compacta à esquerda, expansível.
- Área central ampla para edição e Dashboard inicial.
- Prévia ao vivo à direita, com modos Desktop, Tablet, Mobile e tela cheia.

## Proteções desta versão
- A publicação no GitHub está intencionalmente desativada nesta branch de avaliação.
- Rascunho local e backup continuam disponíveis.
- Nenhum merge foi feito na branch main.
- Os módulos existentes de edição, temas, imagens e regras foram preservados.

## Como testar no Windows
1. Baixe o ZIP desta branch e extraia a pasta.
2. Abra a pasta extraída e entre na pasta `site`.
3. Na barra de endereço do Explorador de Arquivos, digite `cmd` e pressione Enter.
4. Execute `py -m http.server 8000`. Se o comando não existir, tente `python -m http.server 8000`.
5. Mantenha a janela aberta e acesse `http://localhost:8000/editor.html` no navegador.
6. Para encerrar o servidor, volte à janela do terminal e pressione Ctrl+C.

Não abra o editor diretamente como arquivo `file://`: o editor carrega JSON e a prévia por requisições locais, então precisa de um servidor HTTP.

## Roteiro sugerido
- Navegue pelo Dashboard, Site, Regras, Temas e Mídias.
- Expanda e recolha a navegação.
- Edite um campo e confira a atualização da prévia.
- Teste Desktop, Tablet, Mobile e Tela cheia (ESC retorna ao Studio).
- Salve um rascunho e gere um backup.
- Confira que o botão de publicação está desativado nesta versão.

Esta é uma prévia para avaliação. A integração na main depende da aprovação expressa da pessoa responsável pelo projeto.
