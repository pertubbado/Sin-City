PRÉVIA AO VIVO · SIN CITY ROLEPLAY

Conectar ao GitHub

Esta conexão usa um token de acesso refinado do GitHub, limitado ao repositório Sin-City. O token é solicitado somente no seu navegador e não é incluído no código.

  1. Abra a página para criar um token de acesso refinado.
  2. Em Repository access, escolha Only select repositories e marque Sin-City.
  3. Em Repository permissions, defina Contents: Read and write. Não conceda permissões extras.
  4. Gere o token e cole-o no campo abaixo. O GitHub mostra o valor completo apenas uma vez.
Este editor usa o token somente neste navegador, guardando-o na sessão atual. Use apenas num computador confiável e feche a aba quando terminar. Nunca cole o token em conversas ou no código do site.
